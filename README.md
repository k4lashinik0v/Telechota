# Telechota

Site de vídeos com tema preto e amarelo, feito em HTML, CSS e JavaScript para publicar no GitHub Pages.

## Como colocar no GitHub
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e este `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`, e salve.
5. Aguarde o GitHub Pages publicar o site.

## Importante
Esta versão é um protótipo de interface: pesquisa, filtros, cards, modal de vídeo e prévia de publicação funcionam no navegador. Os vídeos de exemplo são ilustrativos; não há upload real, login, armazenamento permanente, comentários nem banco de dados. Para um site público no estilo YouTube, será necessário conectar um backend e armazenamento de vídeos. O GitHub Pages hospeda arquivos estáticos e não recebe uploads de usuários por conta própria.
